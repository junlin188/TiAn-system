# 星闪提案系统 

这是一个纯 PHP + SQLite + 本地文件存储的系统。

## 运行方式

需要 PHP 8.1+，并启用以下扩展：

- `pdo_sqlite`
- `fileinfo`
- `gd`，用于图片验证码；没有时验证码会退化为纯文本响应
- `mbstring`，建议启用，用于中文截断显示

启动开发服务器：

```bash
php -S 127.0.0.1:8001 -t public
```

浏览器访问：

```text
http://127.0.0.1:8001
```

第一次访问会自动创建 SQLite 数据库和示例数据。

## 功能范围

- 管理员：提案文件、用户管理、提案管理。
- 首席会员：提案文件、提案管理；在提案管理中上传、删除、重命名自己负责提案的文件。
- 普通会员：仅提案文件；只能查看、下载、预览授权目录内的文件。
- 文件预览：支持图片和 PDF；Office 等其他格式下载。
- 文件存储：`storage/uploads`。
- 数据库：`storage/app.sqlite`。

## 注意

本项目没有接邮件、对象存储或真实多语言切换。注册和忘记密码入口保留为联系管理员提示。
